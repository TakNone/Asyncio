# Security Policy

Security is a high priority for `taknone/asyncio` We are committed to addressing any security vulnerabilities that may arise

## Supported Versions

Only the latest stable version of `taknone/asyncio` receives security updates. If you are using an older version, we highly recommend upgrading to the latest release to ensure you have the latest security patches

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue on GitHub. Public disclosure of vulnerabilities can put users at risk

Instead, please report it privately via email :

**Email :** `MrTakNone@gmail.com`

### What to include in your report :

To help us resolve the issue as quickly as possible, please provide the following information :

* **Description :** A clear description of the vulnerability
* **Steps to Reproduce :** A list of steps or a code snippet that triggers the issue
* **Impact :** A summary of how this vulnerability could be exploited
* **Environment :** Details about your PHP version ( e.g., `8.4` ), operating system, and any extensions enabled ( e.g., `swoole`, `pcntl` )

We will acknowledge your report within 48 hours and work with you to fix the issue. We appreciate your efforts in keeping this project secure

## Disclosure Policy

Once the vulnerability has been patched and a new version is released, we encourage you to follow responsible disclosure practices. We will credit you in the release notes for finding the vulnerability, if you wish
